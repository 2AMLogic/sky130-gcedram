# Density-vs-SRAM inputs refresh for the post-#244 layout (PROPOSED, not ratified)

Status: **PROPOSED. Not ratified.** Issue #252 (split out of #249). This record
changes no ratified value: `spec/retention-refresh-budget.md` is not edited and
the README requirement is not relaxed. It refreshes the evidence write-up
[`density-vs-sram.md`](density-vs-sram.md), whose inputs still described the
pre-#244 uniform-grid layout, and ties that refresh to the still-PROPOSED
[`c-sn-re-ratification-PROPOSED.md`](c-sn-re-ratification-PROPOSED.md), which
deferred it (its Section 4).

## 1. What changed and why

PR #248 (issue #244) regenerated the layout under klayout-tools 0.8.0. The
array bitcell pitch grew from 2.98 x 1.64 um to 2.98 x 1.94 um, so the 2T cell
is larger relative to the quoted SRAM cells. The sign of the conclusion is
unchanged: the 2T cell as drawn does not beat the quoted 6T SRAM cell on area.
