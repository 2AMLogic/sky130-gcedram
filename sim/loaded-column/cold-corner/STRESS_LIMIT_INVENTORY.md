# Stress and limit inventory: write-WL boost and read-WL under-drive (issue #49)

Epic #24 phase 4. **Evidence inventory only. Nothing here is ratified, and no
spec value is changed.** It takes the two candidates from
[`README.md`](README.md) section 3/4 (`rem_vwl_2p0`, `rem_rwl_m0p2`) and lists,
for each, the exact terminal voltages the committed simulations apply, the
documented limit (if any), and what evidence does not exist. Sources are
indexed in [`EVIDENCE_INDEX.md`](EVIDENCE_INDEX.md); every number below is
re-checked against the committed results by
[`check_evidence_index.py`](check_evidence_index.py).

## 1. The only documented voltage statement found (DOC)

For `sky130_fd_pr__nfet_01v8` (and `_lvt`): "Operating Voltages where SPICE
models are valid: V_DS = 0 to 1.95 V, V_GS = 0 to 1.95 V, V_BS = +0.3 to
-1.95 V". This is a **model-validity range**. It is not an absolute-maximum
rating, not a reliability limit and not a recommended operating condition.
The shipped model files themselves (`libs.ref/sky130_fd_pr/spice/`, the
combined library) carry no voltage-limit, SOA or reliability annotation
(header comments are licence text only; keyword search negative).
No other primary document with an oxide, hot-carrier or junction-injection
limit for the 1.8 V device was found (section 5).

## 2. Candidate A: write-wordline boost, `VWL` = 2.0 V (`rem_vwl_2p0`)

Applied only to the selected row's write wordline for a 20 ns pulse
(`TWPULSE`), with `bl` at 0 V (write '0') or 1.8 V (write '1'). Cell:
`M_WR` = `sky130_fd_pr__nfet_01v8`, W/L = 0.42/0.15 um, p-well tied to
ground ([`design/gain_cell_2t.spice`](../../../design/gain_cell_2t.spice)).

| Quantity | Value (source) | Against the DOC range (V_GS 0..1.95 V) |
|---|---|---|
| `M_WR` V_GS peak | 2.0 V when `bl`/`sn` is 0 V (a '0' write; MODEL/STUDY) | **0.05 V above** the 1.95 V validity bound. The run is therefore outside the range for which the models are documented valid. |
| `M_WR` V_GD, write '1' | 2.0 - 1.8 = 0.2 V at the end of the pulse | within |
| `M_WR` V_DS | <= 1.8 V (`bl` 1.8 V, `sn` 0 V at the start of a '1' write) | within |
| `M_WR` V_BS | `sn` undershoot after the wordline falls: stored '0' min -0.139 V (study min over 30 points) -> V_BS = +0.139 V | within +0.3 V (and the Phase 2 baseline has the same -0.135 V undershoot) |
| Stress duty (STUDY-ASSUMPTION) | 20 ns once per write or refresh, and at most once per ~5.03 us refresh bound -> <= ~0.4 % of time at 2.0 V | no lifetime model exists to turn a duty into a limit |
| Stored '1' level, hot | after write up to 1.382 V (sf/125 C, vs 1.222 V baseline); decays to 1.09 V at the refresh bound | n/a |
| Cold stored '1' | 1.024 V fresh, 1.020 V at the bound (fs/-40 C) vs 0.864 / 0.860 V baseline | restores the level the read needs (0.92-1.0 V, README 2c) |
| Read-path V_GS | `M_RD` gate `sn` <= 1.38 V, source 0 V in the selected read | within |

**Rail/driver requirement** (derived from the table, no circuit simulated): a
write-wordline high level of >= 2.0 V (0.2 V above `VDD`), generated by a
boost or a separate rail, with a level-shifting WL driver whose own
devices see the same overdrive; only the write wordline is boosted (read
wordline stays 0 .. 1.8 V). Driver, pump, settling and ripple tolerance are
**not designed or simulated**.

**Junction-current concerns**: none new. The sn undershoot junction forward
bias (+0.139 V) is the same as the ratified-baseline behaviour.

**Retention-assumption conflict**: it improves it. The retention derivation
assumes `delta_V` = `VDD`/2 = 0.9 V of usable decay; the baseline cold stored
'1' (0.864 V) is below that value, boost gives 1.02 V. However, a boosted
level makes the **hot** hold decay larger in absolute terms (sf/125 C
1.377 -> 1.086 V at the bound) and increases the deselected-row current into
`rbl` (README section 3), reducing the hot minimum separation 0.515 -> 0.435 V.
Note the study used the extracted `C_SN` = 0.605354 fF, whereas the
ratified retention figure uses an ASSUMED 1.106463 fF; the two are not
reconciled by this work (they are Phase-1 and Phase-2 inputs respectively).

## 3. Candidate B: selected read-wordline under-drive, -0.2 V (`rem_rwl_m0p2`)

Applied to the selected row's `rwl` for the 20 ns read; deselected rows keep
`rwl` = 1.8 V; `rbl` precharged to `VRBL` = 0.9 V. `M_RD` is
`sky130_fd_pr__nfet_01v8`, source = `rwl`, drain = `rbl`, p-well at ground.

| Quantity | Value (source) | Against the DOC range |
|---|---|---|
| `M_RD` source voltage | -0.2 V | below the grounded p-well |
| `M_RD` V_BS (selected cell) | 0 - (-0.2) = **+0.2 V**, i.e. the source/p-well junction is forward-biased by 0.2 V | inside the documented "+0.3 V" bound, so the model is documented valid here; **no forward-injection or latch-up limit is documented** |
| `M_RD` V_GS peak | `sn` + 0.2 V <= 1.222 + 0.2 = 1.42 V | within |
| `M_RD` V_DS | `rbl` (<= 0.9 V) - (-0.2) <= 1.1 V | within |
| `rbl` excursion (MODEL, committed data) | stored '1' drives `rbl` **down to -0.2000 V** at the sense instant in 28 of 30 points (the two fs/-40 C points reach only -0.025 / -0.008 V) | not covered by the V_DS/V_GS statement for this node: `rbl` is the drain of every `M_RD` in the column, so every cell's drain/p-well junction is forward-biased by up to 0.2 V in that case |
| Stored '1' level | unchanged: 0.864 V cold, 1.22 V hot (baseline) | retention conflict below |
| Read disturb | selected 0.082 V, unselected 0.072 V (sf/125 C), limit 0.1 V is a study placeholder | n/a |

**Observation that corrects an inference in `README.md` section 3**: that
section says the forward-biased source-junction current "flows in `rwl` ...
but not in `rbl`". The committed rows show `rbl` itself saturating at the
`rwl` level (-0.2 V), so the column node is also pulled below ground, and
the 0.6-0.87 V worst-case separations of this variant include a swing of
the sense node below the ground rail. This does not invalidate the
simulation; it means (a) the sense input must tolerate a negative common
mode, and (b) the separation figure of this variant is not comparable
one-to-one with the boost variant's separation. The committed README is
left unedited (append-only evidence); this inventory supersedes that one
sentence.

**Rail/driver requirement**: a negative supply of <= -0.2 V for the selected
read wordline only, a level shifter swinging -0.2 .. 1.8 V (2.0 V swing
into an `rwl` that is shared by a whole row, so its capacitive and
junction load scales with row length), and the sense input must accept a
sub-ground `rbl`. A negative generator in a p-substrate process injects
minority carriers if any junction connected to a negative node is more
forward than the ~0.3 V (documented model bound for V_BS); isolation
(deep n-well) for the array p-well is not modelled here.

**Junction-current concerns**: forward-biased source-to-p-well junction on
the selected row and, because `rbl` follows, forward-biased drain-to-p-well
junctions on the column. The study did not measure junction current or
substrate injection separately: the selected row's `i_into_rbl_*` column
includes the `rwl` junction contribution, so it is not a pure channel
current. The measured `rwl` currents are MODEL values for a diode whose
forward region is not documented as validated.

**Retention-assumption conflict**: the stored '1' stays below the
retention derivation's `delta_V` = `VDD`/2 = 0.9 V assumption at cold
(0.864 V), so the ratified retention figure, which assumes a 0.9 V swing
available, is not supported by this variant's stored level.
The ratified value is not changed; the conflict is recorded.

## 4. Candidate C: operating-range limitation (no supply assist)

No new stress. Phase 2 periphery fails fs/-40 C (separation 0.018 / 0.017 V
fresh/aged, 32 of 128 stored-'1' points never reach the 0.1 V droop) and
passes ss/-40 C only marginally (0.121 / 0.113 V, latency 7.9 / 8.6 ns
against a 10 ns sense instant). A restriction excludes the cold slow-NMOS
corners from the functional claim; it does not remove any simulated stress,
and it contradicts the repo's "PVT corners on every recorded result"
posture unless ratified explicitly.
